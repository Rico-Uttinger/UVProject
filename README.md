# UVProject

A web application for tracking sun exposure time and maximum exposure using UV-Index

## Tech Stack

### Backend
- C#
- ASP.NET Core
- Entity Framework Core
- SQL Server
- REST API
- OpenAPI

### Frontend
- Angular
- TypeScript
- HTML
- CSS

## Project status
Ongoing project - scope: Small but working.

## Vision
- Check current UV-Index based on your location.
- Estimate how long the user can stay in the sun based on the current UV index and skin type.
- Track previous sun exposure.
- Help users become aware of their sun exposure limits.
